First release.

- Chat and Work modes with your own API keys: Claude, OpenAI, OpenRouter, Groq, Gemini and other OpenAI-compatible services.
- Work tools: workspace files, memory, task list, web search and code sandbox (Claude models), GitHub and Gmail connections. It asks before changing anything.
- Several chats and pieces of work run at once and keep going in the background.
- Scheduled tasks, voice typing, and a greeting that follows the hour and your weather.
- Encrypted sync between up to five devices, paired by QR code. Share a single chat by code.
- Android, Windows and Linux with the same interface; landscape layout on computers.
- Updates itself from GitHub releases.
